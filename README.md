## 📥 程式下載步驟

1. 在**桌面**新增一個資料夾，資料夾名稱請設為你的**學號**。
2. 點選 [`game.py`](./game.py)，並點擊程式碼右上角的 **Download raw file** 按鍵（下載圖示），將檔案儲存至桌面的**學號資料夾**。
3. 點選 [`character.py`](./character.py)，並點擊程式碼右上角的 **Download raw file** 按鍵，將檔案儲存至桌面的**學號資料夾**。
4. 打開 **VS Code**，並開啟這個**學號資料夾**開始撰寫程式。

---

## 📂 檔案架構說明

### `character.py`
* 主要撰寫**三種類別**：分別為 **磚塊**、**球**、**木棒**。
* 請依照檔案內的**註解內容**完成撰寫。

### `game.py`
* 主要撰寫**遊戲主邏輯**。
* 包含：**群組建立**、**實體化物件**、**碰撞偵測**、**遊戲關閉**。

---

## 💯 評分方式（滿分 100 分）

依下列 5 項功能完成度給分：

1. **木棒控制**：產生木棒，可透過鍵盤**左、右鍵**控制移動，且移動範圍**不能超出視窗邊界**。
2. **球的移動與邊界反彈**：產生球，碰到視窗**左、右、上**邊界皆會反彈；碰到**下方邊界不反彈**。
3. **磚塊群排列**：產生磚塊群，一共為 **5 列**，每列有 **10 個**磚塊，總共 **50 個磚塊**。
4. **碰撞偵測**：
   * 球碰到**木棒**會反彈。
   * **磚塊**碰到球會消失，且**球**也會隨之反彈。
5. **遊戲結束機制**：當球**掉落出底下視窗**時，自動關閉遊戲。
